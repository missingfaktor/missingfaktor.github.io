Replace bathroom-door locks

Posted on 22 July 2026

Neither bathroom door has a conventional privacy lock. Each currently uses an awkward screw-operated control, and there is no way to release the door from outside if someone inside cannot open it.

Fit a chrome bathroom lock to each door, matching the existing handles:

  • A thumb turn inside.
  • An emergency coin release outside.
  • Redundant holes and finish damage made good.

Materials

  • Two compatible chrome bathroom thumb-turn lock sets with emergency coin releases
  • Fixings
  • Wood filler
  • Touch-up finish, if required
DIY fallback Reasonable

This is achievable DIY carpentry once the existing lock arrangement, door thickness and backset are measured and compatible chrome lock sets have been chosen.

Fallback approach

  • Remove one existing control carefully and measure the door thickness, backset, spindle and available case depth before buying both sets.
  • Use the supplied template to mark each door and confirm that the thumb turn and coin release will align with the existing handles.
  • Drill and chisel in small stages, keeping the lock case and faceplate square rather than enlarging the opening at once.
  • Fit and test each door repeatedly, including the outside emergency release, before making good redundant holes.

Tools and supplies

  • Tape measure and combination square
  • Drill-driver with wood bits or the required hole saw
  • Sharp wood chisels and rubber mallet
  • Screwdrivers
  • Lock-fitting jig if the chosen case requires one
  • Clamps, eye protection and dust extraction

Stop and hand over if

  • The existing mechanism cannot be identified or the new case would remove substantial timber.
  • The door is fire-rated or contains construction that the chosen lock has not been approved for.
  • The latch, thumb turn or emergency release cannot operate freely with the door both open and closed.
