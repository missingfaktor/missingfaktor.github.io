Install jet sprays in both bathrooms

Posted on 22 July 2026

Neither toilet has a hygienic jet spray. Install one beside each, including any required isolation valves and suitable plumbing connections.

The products will be supplied after a plumber has confirmed the required type and compatibility, so nothing should be bought before that.

A handset on a hose that can fall below the toilet spill-over level may require Fluid Category 5 backflow protection, so the connection method has to be specified rather than assumed.

Materials

  • Two compatible jet-spray kits
  • Isolation valves
  • Hoses and connectors
  • Wall fixings
DIY fallback Not recommended

The installation itself is not a DIY fallback. An incorrect connection can leak, create pressure problems, or allow contamination of the drinking-water supply.

Fallback approach

  • Photograph the accessible supply arrangement beside each toilet and note whether a local isolation valve is visible.
  • Measure the intended handset position and hose reach without disconnecting any plumbing.
  • Wait to buy the spray kits, valves and connectors until the connection and backflow-protection requirements have been specified.

Tools and supplies

  • Tape measure
  • Camera or phone for reference photographs

Stop and hand over if

  • Any step requires loosening or altering the toilet supply.
  • There is no clearly identified local isolation point.
  • Compatibility, pressure or backflow protection remains uncertain.
