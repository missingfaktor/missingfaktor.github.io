Install bathroom caddies

Posted on 22 July 2026

Install three customer-supplied caddies per shower unit and one per bath unit. Position them for convenient access and use fixings appropriate for tiled, wet-area walls.

Materials

  • Customer-supplied caddies
  • Tile-safe drill bits
  • Waterproof fixings
  • Sanitary sealant
